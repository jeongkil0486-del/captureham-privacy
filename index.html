캡처함 개인정보처리방침

캡처함은 사용자의 스크린샷과 일정 정보를 가능한 한 기기 안에서 안전하게 처리합니다.

최초 시행일: 2026년 7월 24일 · 개정 및 시행일: 2026년 8월 11일

제1조 목적

이 개인정보처리방침은 JG Studio KR이 제공하는 모바일 애플리케이션 캡처함이 사용자의 개인정보 및 기기 데이터를 어떻게 처리하는지 안내하기 위해 작성되었습니다.

제2조 수집 및 처리하는 정보

캡처함은 사용자가 선택한 기능을 제공하기 위해 다음 정보를 처리할 수 있습니다.

  • 사용자가 직접 선택·공유하거나 자동 감지 기능으로 확인한 스크린샷
  • 실시간 스캔 또는 촬영 기능에서 사용하는 카메라 이미지
  • OCR로 인식한 문구와 위치 정보, 날짜, 시간, 장소, 전화번호, 이메일, URL, 금액 등의 분석 결과
  • 일정 제목, 날짜, 시간, 장소, 메모, 알림 설정 및 캘린더 등록 상태
  • 온보딩 완료 여부, 권한 안내 상태, 기능 설정 등 앱 환경설정
  • 광고 제공 과정에서 Google Mobile Ads SDK가 처리할 수 있는 광고 관련 식별자 등 정보(제8조 참고)

중요

  • 캡처 이미지와 OCR 본문은 JG Studio KR의 서버로 전송하지 않습니다.
  • 결제수단, 카드번호 및 Google 계정 이메일에는 앱이나 개발자가 접근하지 않습니다.
  • 캡처함은 회원가입·로그인·인앱결제·구독 기능을 제공하지 않으며, 자체 구매 검증 서버를 호출하지 않습니다.
  • 개인정보를 판매하지 않습니다.

권한 사용

  • 카메라: 사용자가 실시간 스캔 또는 촬영 분석을 실행할 때 사용합니다.
  • 사진 및 미디어: 사용자가 선택·공유한 이미지와, 자동 감지를 켠 경우 새 스크린샷을 확인할 때 사용합니다.
  • 알림: 자동 감지 실행 상태, 캡처 분석 안내 및 사용자가 설정한 일정 알림을 표시할 때 사용합니다.
  • 정확한 알람: 사용자가 선택한 시각에 일정 알림을 제공할 때 사용합니다.
  • 포그라운드 서비스: 사용자가 자동 감지를 켠 동안 기능을 유지하고 Android 알림 영역에 실행 상태를 표시할 때 사용합니다.

사용자는 Android 설정에서 권한을 철회할 수 있으며, 해당 권한이 필요한 기능은 제한될 수 있습니다.

제3조 스크린샷·카메라·OCR 처리

캡처함은 이미지 속 글자를 확인하기 위해 Google ML Kit Text Recognition을 사용하며, OCR 분석은 기기에서 수행됩니다.

  • 스크린샷 또는 카메라 이미지에서 일정·장소·연락처·링크·금액 후보를 찾습니다.
  • 이미지와 OCR 본문을 개발자가 운영하는 별도 OCR 서버로 전송하거나 저장하지 않습니다.
  • 사용자가 저장 기능을 선택하면 원본 이미지와 OCR 문구·좌표가 일정과 함께 앱 전용 로컬 저장공간에 보관될 수 있습니다.
  • 실시간 카메라 분석 중인 프레임은 분석 목적으로 사용되며, 사용자가 촬영·저장한 결과만 앱 전용 저장공간에 남을 수 있습니다.

제4조 기기 내부 데이터 저장

다음 정보는 기능 제공과 사용자 선택을 유지하기 위해 기기 내부에 저장될 수 있습니다.

  • 일정 제목, 날짜, 시간, 장소, 메모 및 알림 정보
  • 저장한 일정에 연결된 이미지, OCR 문구 및 좌표
  • 임시 공유 이미지 캐시
  • 온보딩, 권한 안내, 자동 감지 등 앱 설정

캡처함에는 자체 일정/OCR 동기화 서버가 없으며, 위 로컬 데이터를 개발자 서버와 동기화하지 않습니다.

제5조 데이터 삭제

  • 보관함에서 일정을 개별 또는 여러 개 선택해 삭제할 수 있습니다.
  • 저장된 일정 모두 삭제를 실행하면 일정 DB, OCR 문구·좌표, 관련 알림, 일정 연결 이미지, 다른 일정이 참조하지 않는 고아 이미지 및 임시 공유 이미지 캐시를 정리합니다.
  • 여러 일정이 같은 이미지를 참조할 때는 남아 있는 일정에 필요한 이미지를 보호합니다.
  • 시스템 캘린더에 사용자가 직접 저장한 일정은 캡처함의 삭제 기능으로 삭제되지 않습니다.
  • 앱을 삭제하면 운영체제가 앱 전용 로컬 데이터를 삭제합니다.

제6조 Android 백업 정책

캡처함은 민감한 캡처 및 OCR 데이터가 Android 자동 백업이나 기기 간 데이터 이전으로 복사되지 않도록 앱 백업을 명시적으로 비활성화했습니다.

  • 앱 내부 파일과 앱 전용 외부 파일
  • SQLite 데이터베이스
  • SharedPreferences 설정
  • 기기 보호 저장소의 앱 데이터

위 데이터는 Google Cloud Backup 및 Android 기기 간 이전 대상에서 제외되도록 구성되어 있습니다.

제7조 Google ML Kit

캡처함은 이미지 속 글자를 인식하기 위해 Google ML Kit Text Recognition SDK를 사용합니다. 이미지와 OCR 결과 자체는 JG Studio KR의 서버로 전송하지 않습니다.

Google의 공식 데이터 공개 안내에 따르면 ML Kit SDK는 진단 및 사용 분석을 위해 다음과 같은 앱·기기 정보를 처리할 수 있습니다.

  • 기기 제조사·모델·운영체제 버전·사용 가능한 ML 하드웨어 가속기
  • 앱 패키지명과 앱 버전
  • 설치 단위 식별자 등 기기 또는 기타 식별자
  • 처리 지연 시간 등의 성능 지표
  • 이미지 형식·해상도 등의 API 설정과 입력·출력 크기
  • 기능 버전, 초기화·감지·리소스 해제 등의 이벤트 유형 및 오류 코드

Google의 공개 안내에 따르면 이 데이터는 HTTPS로 전송 중 암호화되며, ML Kit 데이터 공개 범위에서 제3자에게 전송되지 않습니다. 자세한 내용은 Google ML Kit Android 데이터 공개 안내에서 확인할 수 있습니다.

제8조 광고(Google AdMob)

캡처함은 앱 운영 및 무료 서비스 제공을 위해 Google AdMob(Google Mobile Ads SDK)을 사용해 광고를 표시할 수 있습니다.

  • 보관함 화면 하단에 배너 광고가 표시될 수 있습니다.
  • 일정을 일정 횟수 이상 저장하면 전면 광고가 표시될 수 있습니다.

광고를 제공하는 과정에서 Google Mobile Ads SDK가 기기 식별자, 광고 관련 식별자, 대략적인 위치, 앱 상호작용 정보, 진단 정보 등의 데이터를 처리할 수 있습니다. 이 데이터 처리는 캡처함이 아니라 Google의 서비스 및 개인정보처리방침에 따라 이루어집니다. 자세한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다.

캡처함 또는 개발자는 광고 제공을 목적으로 사용자의 스크린샷 원본, OCR 인식 문구, 일정 제목·장소·메모 등 캡처함 고유 데이터를 Google AdMob이나 그 밖의 서버로 전송하지 않습니다. 광고 SDK가 처리하는 데이터와 캡처함이 기기 내부에서 처리하는 캡처·일정 데이터는 서로 분리되어 있습니다.

캡처함은 개인정보를 판매하거나 데이터 중개업체에 제공하지 않으며, Firebase 제품을 연동하지 않습니다.

제9조 외부 앱 및 서비스 연결

사용자가 관련 버튼을 직접 누른 경우에만 필요한 정보가 외부 앱으로 전달될 수 있습니다.

  • 네이버지도: 장소 검색어
  • 웹 브라우저: 사용자가 선택한 URL
  • 전화·문자 앱: 전화번호
  • 이메일 앱: 이메일 주소
  • Android 캘린더: 일정 제목, 날짜, 시간, 장소 및 메모

외부 앱이 열린 뒤의 처리에는 각 서비스 제공자의 개인정보처리방침과 사용자 기기 설정이 적용됩니다. 외부 앱 실행 실패 로그에는 전화번호, 이메일, 장소, URL 또는 전체 URI 원문을 기록하지 않습니다.

제10조 회원가입 및 계정

  • 회원가입 또는 로그인 기능이 없습니다.
  • 이름, 생년월일, 비밀번호 또는 Google 계정 이메일을 회원 정보로 수집하지 않습니다.
  • 자체 일정/OCR 계정이나 동기화 서비스를 제공하지 않습니다.
  • 인앱결제, 프리미엄 상품, 구독 기능을 제공하지 않으며, 자체 구매 검증 서버를 운영·호출하지 않습니다.

제11조 데이터 보안

  • 캡처 및 OCR 데이터는 앱 전용 로컬 저장공간을 중심으로 처리합니다.
  • Android 자동 백업과 기기 간 이전에서 앱 데이터를 제외하도록 구성합니다.
  • 광고 SDK를 포함한 외부 통신은 HTTPS를 사용합니다.
  • 외부 실행 URI를 로그에 기록하지 않습니다.
  • 필요한 데이터만 처리하고 사용자가 직접 삭제할 수 있는 기능을 제공합니다.

기기 잠금, 운영체제 보안 상태 및 외부 앱의 보안은 사용자의 기기 환경에도 영향을 받습니다.

제12조 개인정보처리방침 변경

  • 앱 기능이나 관련 정책이 변경되는 경우 이 방침이 수정될 수 있습니다.
  • 중요한 변경 사항은 앱 또는 이 공개 페이지를 통해 안내합니다.
  • 사용자는 앱의 개인정보 및 데이터 화면에서 이 공개 방침을 직접 열 수 있습니다.
  • 방침이 변경되면 상단의 개정일 및 시행일을 갱신합니다.
