캡처함 개인정보처리방침

캡처함은 사용자의 스크린샷과 일정 정보를 가능한 한 기기 안에서 안전하게 처리합니다.

시행일: 2026년 7월 24일 · 최종 수정일: 2026년 7월 24일

제1조 목적

이 개인정보처리방침은 JG Studio KR이 제공하는 모바일 애플리케이션 캡처함이 사용자의 개인정보 및 기기 데이터를 어떻게 처리하는지 안내하기 위해 작성되었습니다.

제2조 처리하는 정보

캡처함은 다음 정보를 기능 제공을 위해 처리할 수 있습니다.

  • 사용자가 직접 선택하거나 자동 감지 기능으로 확인한 스크린샷 이미지
  • 스크린샷에서 이미지 속 글자를 확인하는 과정에서 인식한 날짜, 시간, 일정 제목 등의 정보
  • 사용자가 직접 입력한 일정 제목, 날짜, 시간, 장소, 메모
  • 사용자가 설정한 알림 및 앱 설정 정보

중요한 구분

  • 원본 스크린샷을 개발자 서버에 업로드하거나 저장하지 않습니다.
  • 스크린샷에서 인식한 전체 OCR 원문을 개발자 서버에 저장하지 않습니다.
  • 사용자가 최종 확인하고 저장한 일정 정보만 기기에 저장합니다.
  • 사용자가 직접 입력한 메모와 알림 설정은 기기에 저장될 수 있습니다.

제3조 정보 이용 목적

  • 스크린샷에서 일정 후보 확인
  • 일정 날짜와 시간 제안
  • 사용자가 확인한 일정 보관
  • 일정 예정 알림 제공
  • 시스템 캘린더 등록 지원
  • 앱 설정 유지

제4조 저장 위치와 외부 전송

  • 원본 이미지와 글자 인식 결과는 사용자의 기기 안에서 처리됩니다.
  • 원본 스크린샷과 전체 OCR 원문 및 일정 내용을 JG Studio KR의 서버로 전송하거나 저장하지 않습니다.
  • 회원가입이나 계정 생성 기능이 없습니다.
  • 개발자가 운영하는 사용자 데이터 서버와 자체 클라우드 동기화 기능이 없습니다.
  • 자체 광고 SDK가 없으며 광고 목적의 정보 수집을 하지 않습니다.
  • 개인정보를 판매하지 않습니다.
  • 사용자가 최종 저장한 일정, 메모, 알림 설정과 앱 설정은 기기 내부 앱 저장공간에 저장될 수 있습니다.

Google ML Kit 이용

캡처함은 이미지 속 글자를 인식하기 위해 Google ML Kit 한국어 텍스트 인식 SDK를 사용합니다. 원본 스크린샷과 OCR로 인식된 일정 내용은 JG Studio KR의 별도 서버로 전송하거나 저장하지 않습니다.

다만, Google ML Kit는 진단 및 사용 분석을 위해 다음 정보를 처리하여 Google에 전송할 수 있습니다.

  • 기기 제조사 및 모델
  • 운영체제 버전과 빌드 정보
  • 앱 패키지명과 앱 버전
  • 기능 실행 이벤트 등 앱 상호작용 정보
  • 오류 코드 등 진단 정보
  • 처리 시간과 성능 지표
  • 설치 단위 식별자 등 기기 또는 기타 ID

해당 정보는 애널리틱스, 진단 및 앱 성능 확인 목적으로 사용될 수 있습니다. 이 SDK의 진단 데이터 처리는 사용자가 캡처함 설정에서 별도로 끄는 선택 기능으로 제공되지 않습니다.

Google의 공개 안내에 따르면 해당 데이터는 HTTPS를 통해 전송 중 암호화되며, ML Kit 데이터 공개 범위에서 제3자에게 공유되지 않습니다. 자세한 내용은 Google ML Kit Android 데이터 공개 안내에서 확인할 수 있습니다.

사용자의 원본 이미지와 일정 내용은 개발자 서버로 전송하지 않지만, 앱에 포함된 Google ML Kit는 위와 같은 진단 및 사용 분석 데이터를 처리할 수 있습니다.

사용자가 캘린더에 추가를 선택하면 Android 시스템 캘린더 등록 화면이 열릴 수 있으며, 최종 저장 여부는 사용자가 해당 화면에서 직접 확인하고 결정합니다. Google Calendar 등 외부 캘린더와의 동기화는 사용자의 계정과 시스템 설정에 따라 해당 서비스의 개인정보처리방침이 적용될 수 있습니다.

제5조 권한 사용

사진 및 미디어 접근

  • 사용자가 직접 선택한 사진 또는 스크린샷을 분석하기 위해 사용합니다.
  • 사용자가 자동 감지를 켠 경우 새로 생성된 스크린샷을 확인하기 위해 사용합니다.
  • 앱 기능에 필요한 범위에서만 사용합니다.

알림 권한

  • 자동 감지 실행 상태를 표시하기 위해 사용합니다.
  • 스크린샷에서 확인한 일정 후보를 알리기 위해 사용합니다.
  • 사용자가 설정한 일정 알림을 표시하기 위해 사용합니다.

정확한 알람 권한

  • 사용자가 설정한 시각에 맞춰 일정 알림을 표시하기 위해 사용합니다.

포그라운드 서비스(자동 감지 실행 상태 표시)

  • 사용자가 자동 감지를 직접 켠 동안 새 스크린샷 감지 기능을 유지하기 위해 사용합니다.
  • 실행 중에는 Android 알림 영역에 지속 알림으로 상태를 표시합니다.

배터리 최적화 예외

  • 자동 감지 기능이 중간에 중단되지 않도록 사용자가 선택적으로 설정할 수 있습니다.
  • 필수 권한이 아니며, 설정하지 않아도 앱의 다른 기능은 계속 사용할 수 있습니다.

캘린더

  • 사용자가 캘린더에 추가를 직접 선택한 경우에만 Android 시스템 캘린더 등록 화면이 열릴 수 있습니다.
  • 최종 저장 여부는 사용자가 해당 화면에서 직접 확인하고 결정합니다.

사용자는 Android 설정에서 사진, 알림 및 관련 권한을 철회할 수 있습니다. 권한을 거부하거나 철회하면 사진 선택, 자동 감지, 일정 후보 알림 또는 정확한 일정 알림 등 해당 권한이 필요한 기능이 제한될 수 있습니다.

제6조 보관 기간

  • 저장한 일정과 앱 설정은 사용자가 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다.
  • 보관함 화면에서 개별 일정을 삭제할 수 있습니다.
  • 앱의 개인정보 및 데이터 화면에서 앱 데이터 삭제 기능을 사용할 수 있습니다.
  • 앱을 삭제하면 기기 내부 앱 데이터가 운영체제에 의해 삭제될 수 있습니다.
  • 시스템 캘린더에 별도로 추가한 일정은 캡처함을 삭제해도 캘린더 앱에 남아 있을 수 있습니다.

제7조 제3자 제공

  • JG Studio KR은 사용자 데이터를 광고회사나 데이터 중개업체에 판매하거나 공유하지 않습니다.
  • 앱에 포함된 Google ML Kit SDK의 운영 과정에서는 진단 및 사용 분석 데이터가 Google에 전송될 수 있습니다. Google의 공개 안내에 따르면 ML Kit 데이터 공개 범위에서 해당 데이터는 제3자에게 공유되지 않습니다.
  • 사용자가 시스템 캘린더에 직접 저장하거나 Android 공유 기능을 이용한 경우에는 해당 서비스 제공자의 정책이 적용될 수 있습니다.

제8조 아동의 개인정보

  • 캡처함은 별도의 회원가입이나 생년월일 수집 기능이 없습니다.
  • 아동의 개인정보를 의도적으로 수집하는 서비스가 아닙니다.
  • 보호자가 문의할 사항이 있는 경우 아래 안내된 이메일로 연락할 수 있습니다.

제9조 사용자의 권리

사용자는 다음을 언제든지 직접 할 수 있습니다.

  • 저장한 일정 열람
  • 일정 수정
  • 일정 삭제
  • 앱 설정 변경
  • 사진 및 알림 권한 해제
  • 자동 감지 기능 중지
  • 앱 데이터 삭제
  • 앱 삭제

제10조 보안

  • 불필요한 원본 이미지와 인식 원문을 영구 저장하지 않습니다.
  • 앱 내부 저장공간을 중심으로 데이터 노출을 최소화합니다.
  • 사용자 기기의 잠금 설정, 백업 방식, 악성 앱 설치 여부 등 운영체제 수준의 보안은 사용자의 기기 환경에도 영향을 받을 수 있습니다.

제11조 개인정보처리방침 변경

  • 앱 기능이나 관련 정책이 변경되는 경우 이 방침이 수정될 수 있습니다.
  • 중요한 변경 사항은 앱 또는 이 공개 페이지를 통해 안내합니다.
  • 방침이 변경되면 상단의 시행일을 갱신합니다.
